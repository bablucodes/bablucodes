## Featured Projects

### [MERN eCommerce](https://github.com/bablucodes/Mern-Project)

A full-stack e-commerce application with a React/Vite frontend and an Express/MongoDB backend.

- **Technologies:** React, Vite, Node.js, Express, MongoDB, Mongoose, JWT, bcryptjs, Axios
- **Features:** Signup and login flows, product browsing, a shopping cart interface, and admin product-management pages.
- **Repository:** [GitHub Repository](https://github.com/bablucodes/Mern-Project)
- No live demo is listed in the repository.

### [Weather App](https://github.com/bablucodes/weather-app)

A responsive weather dashboard that fetches current conditions through a Vercel serverless API.

- **Technologies:** HTML, CSS, JavaScript, WeatherAPI, Vercel Functions
- **Features:** Search by city or region, device-location weather, current-condition details, Celsius/Fahrenheit switching, and server-side API requests.
- **Links:** [GitHub Repository](https://github.com/bablucodes/weather-app) · [Live Demo](https://weather-app-one-gamma-74.vercel.app/)

### [EduPulse — Student Engagement Analytics](https://github.com/bablucodes/edupulse-student-engagement)

A Streamlit dashboard for exploring student-engagement data and presenting insights from the supplied dataset.

- **Technologies:** Python, Streamlit, Pandas, Plotly, NumPy
- **Features:** Engagement scores, risk categories, student analysis, faculty intervention suggestions, filters, and downloadable reports.
- **Links:** [GitHub Repository](https://github.com/bablucodes/edupulse-student-engagement) · [Live Demo](https://edupulse-student-engagement.streamlit.app/)
- The live URL has been provided, but public accessibility should be confirmed in a normal browser session.

### [EcoAgent — Smart Home Energy Assistant](https://github.com/bablucodes/AICTE-INTERNSHIP-PROJECT)

A Streamlit energy assistant for estimating household appliance usage and reviewing estimated energy summaries.

- **Technologies:** Python, Streamlit, Pandas, NumPy, scikit-learn, SQLite
- **Features:** Appliance energy estimates, usage projections, energy-saving suggestions, reports, and an admin dashboard. The project uses a Random Forest prediction blended with a standard energy formula. These are educational estimates, not meter readings.
- **Repository:** [GitHub Repository](https://github.com/bablucodes/AICTE-INTERNSHIP-PROJECT)

### [Product Catalog](https://github.com/bablucodes/Product-Catlogs)

An ASP.NET Core MVC application for managing and browsing product records.

- **Technologies:** C#, ASP.NET Core MVC, Razor
- **Features:** Create, view, edit, and delete products; search by name or category; and sort by price. Product records are held in memory.
- **Repository:** [GitHub Repository](https://github.com/bablucodes/Product-Catlogs)
